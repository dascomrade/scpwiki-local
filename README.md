## a locally run version of the SCP Wiki. With a consistent article design

I mean, have you seen the difference between lets say 049 and 5041? how is a new fan supposed to understand what all the fancy words mean like Keter, Keneq? 
sure if you searched for a while through the wiki you'd find the page that explains what everything means, but most people dont know to search for "SCP Anomaly Classification System"
This is the main reason I decided to make this project, with the secondary reason being wanting the application to be able to work without internet and on old devices, mainly in the name of being more "immersive" and allowing custom entities to be used
